# DetLan — Слідство веде детектив (Detective Language) 🕵️‍♂️🇧🇬

> **PWA-додаток для вивчення болгарської мови (рівні A1–A2) у стилі класичного детективу Еркюля Пуаро та Агати Крісті.**

---

## 🌟 Основні особливості

1. **Атмосфера 1930-х років та Еркюля Пуаро**:
   - Елегантний вінтажний Art Deco дизайн (глибокий нічний колір, золото, пергамент, воскові печатки).
   - Інтерактивна дошка розслідувань («Crime Board») з корковою текстурою, фотокартками підозрюваних та червоними нитками дедукції.
   - Синтезовані через Web Audio API звуки друкарської машинки, дзвінка доказів, удару молотка/печатки та напруги допиту (працює офлайн без зовнішніх mp3!).

2. **Анімований промо-лендинг (Showcase)**:
   - Інтерактивний тестер слів-пасток («Сірі клітинки») безпосередньо на першому екрані.
   - Демонстрація системи детективних рангів та сюжетних епізодів.

3. **Авторизація через Google / Supabase + Режим Гостя**:
   - Інтегрований клієнт Supabase для Google OAuth та входу за поштою.
   - Моментальний **«Швидкий вхід як Запрошений Детектив (Demo)»** для миттєвого тестування без необхідності попереднього налаштування ключів.

4. **Ігровий процес у форматі Duolingo + Детектив**:
   - **Справа №1: «Справа про зниклий ключ» (Гранд-Готель «Балкан», Софія)**:
     - *Етап 1: Показання портьє Бояна* — аудіозапис болгарською мовою (Web Speech API) та питання на розуміння часу й номеру кімнати.
     - *Етап 2: Записка біля дверей* — виявлення небезпечної пастки напрямку (`направо` = **прямо**! А праворуч — `надясно`).
     - *Етап 3: Очна ставка з портьє (Бос епізоду)* — допит на час під цокання таймера, викриття неправдивого алібі з різницею в 30 хвилин.
   - Нагороди: +70 XP, «Ключ від мансарди», бейдж «Гостре око», +1 «Алібі».

5. **Система «Алібі» та боротьба з вигоранням**:
   - Заморозка серії («Алібі»), що рятує ваш щоденний Streak у разі пропущеного дня.
   - Щоденні короткі тренування слів (+10 XP).

6. **Кишеньковий записник Пуаро**:
   - Словник речових доказів з озвучкою кожного болгарського слова.
   - Досьє небезпечних «Хибних друзів перекладача» (`направо`=прямо, `гора`=ліс, `диня`=кавун, `стол`=стілець, `майка`=мама, `булка`=наречена тощо).
   - Секрети болгарської граматики (відсутність відмінків, кінцеві артиклі `-ът`, `-та`, `-то`, `-те`, звук `ъ`).

7. **PWA (Progressive Web App)**:
   - Встановлюється на робочий стіл або головний екран смартфону (iOS / Android / Windows / macOS).
   - Працює офлайн завдяки Service Worker (`/sw.js`) та `manifest.webmanifest`.

---

## 🚀 Запуск проєкту

### 1. Встановлення залежностей (вже виконано)
```bash
npm install
```

### 2. Запуск локального сервера розробки
```bash
npm run dev
```

### 3. Збірка для продакшну
```bash
npm run build
```

---

## 🔑 Підключення Supabase (Опціонально)

Створіть файл `.env` у корені проєкту (на основі `.env.example`):
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here
```
У панелі Supabase увімкніть Google Provider у розділі Authentication -> Providers.
*(Якщо ключі не вказані, додаток працює в автономному режимі з локальним збереженням прогресу).*
